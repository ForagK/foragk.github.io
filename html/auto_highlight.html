auto_highlight.auto_highlight.focus_check(char_name, anim_length, anim_time, ease_func=<function get_ease>, dict_ref=0)

Checks a character’s speaking status and computes the current animation easing value.

Parameters:

  • char_name (str) – Name or tag of the character whose focus state is being evaluated.

  • anim_length (float) – Duration of the focus animation in seconds.

  • anim_time (float) – Current animation time value used as a reference for calculating transition progress.

  • ease_func (Callable[[float], float], optional) – Easing function used to interpolate animation progress. The function receives a normalized value between 0.0 and 1.0 and should return the corresponding eased value. Defaults to get_ease.

  • dict_ref (Hashable, optional) – Key used to select which focus dictionary inside sprite_focus should be used. This allows multiple independent focus systems. Defaults to 0.

Returns:

A tuple containing the following elements:

  • status(bool): Whether the character is currently considered to be speaking.

  • curr_ease(float): Current eased animation progress in the range [0.0, 1.0]

Return type:

tuple
